# Hun Jeong — Portfolio

과학교육 박사과정 연구자 Hun Jeong의 개인 포트폴리오 사이트입니다.

## 기술 스택

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS + Inline styles
- **배포**: Vercel

## 로컬 개발

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 접속

## Vercel 배포

1. [vercel.com](https://vercel.com)에서 GitHub 저장소 연동
2. `portfolio-site` 폴더를 루트로 설정하거나, 해당 폴더를 별도 저장소로 푸시
3. 자동 배포 완료

또는 Vercel CLI 사용:

```bash
npm i -g vercel
vercel --prod
```
